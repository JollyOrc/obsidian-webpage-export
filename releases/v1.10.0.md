# Webpage HTML Export (Raiders of Arismyth fork) 1.10.0

**Released:** 2026-10-31
**Based on:** upstream Webpage HTML Export 1.9.2 (`78c973d`)

The first release of the fork. It makes exports of notes with embeds
complete and stops the export from freezing Obsidian.

## Changed behaviour

- **Notes are rendered off screen.** Each note's Markdown is rendered with
  Obsidian's `MarkdownRenderer.render` into an element outside the window,
  instead of in the reading view. The reading view draws only the sections
  near the visible area; upstream waited for them, timed out and fell back,
  and in the author's vault that froze Obsidian. Measured on the author's
  desktop: a full export of 410 pages in about 40 seconds, no freeze.
- **No automatic fallback.** Upstream switched to its fallback renderer
  when a note's sections were not all drawn. The fallback now runs only
  with the export setting `useFallbackRenderer: true`; when it runs, it
  waits until every embed has content before it copies the page.
- **Embedded notes' properties stay out of the page.** Upstream moved the
  first frontmatter it found anywhere on the page, often an embedded
  note's, to the top of the page. Now only the page's own frontmatter
  moves; frontmatter inside embeds is removed.
- **Virtual Linker links follow `onlyLinkOnce`.** With that setting on, the
  export now links far fewer occurrences of a term (measured on one page:
  `Kari` 27 times before, once now), as the setting asks.

## Bug fixes

- Embeds lost their content when a paragraph held two of them (upstream's
  "div inside p" step emptied or nested them).
- The fallback copied pages before embedded notes had loaded.
- An embed that still shows nothing after rendering gets a visible
  placeholder ("Embedded content could not be exported: …") and a warning
  in the export log, unless its target is genuinely empty.

## Breaking changes and migration

- None for settings: the plugin id (`webpage-html-export`) and all settings
  are unchanged. Install the release's `main.js`, `manifest.json` and
  `styles.css` into the vault's `.obsidian/plugins/webpage-html-export/`
  folder (or through BRAT).
- The plugin id is upstream's: Obsidian's community browser may offer
  upstream's releases as updates of this fork.
- Pages are drawn by a different renderer. Heading arrows, embed icons and
  page classes are written as the reading view wrote them; whether the site
  shows heading arrows still follows `allowFoldingHeadings`.
