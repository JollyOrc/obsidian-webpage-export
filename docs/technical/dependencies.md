# Dependencies and Build Requirements

> Keep this file coherent with `../user-stories/README.md` and `tests.md`.

## Build

- Node and npm; `npm install`, then `npm run build`
  (`tsc -noEmit -skipLibCheck && node esbuild.config.mjs production`).
- `npm run dev` builds in watch mode.
- Tests (US-001): `npm test` needs a Node that runs `.ts` files directly
  (type stripping; the fixture generator runs as `node tests/fixtures/generate.ts`).
  Measured on Node 26.12; the release workflows use `26.x`. On Node 20 the
  generator fails (`ERR_UNKNOWN_FILE_EXTENSION`, release run 2026-10-31);
  versions between are not measured. Vitest 3.2.7;
  `npm run test:integration` needs Docker with BuildKit (measured with
  Docker 29.9.2, arm64). The test image is upstream's `Dockerfile` built with
  `--build-arg OBSIDIAN_VERSION=1.14.5` (Obsidian 1.14.5, the author's app;
  upstream's default 1.9.12 is unchanged), `--build-arg
  PLUGIN_STAGE=plugin-local` and `--build-context localplugin=<dir with the
  local main.js, manifest.json, styles.css>` (`.dockerignore` excludes
  `main.js`). Injected script: `tools/headless/export-report.mjs`, mounted
  over the image's `/export-vault.mjs`, which stays unchanged.
  `electron-injector` 1.0.2 panics after the script under Obsidian 1.14.5
  (spike addendum); the script's own run report replaces the console log.
- Desktop only (`isDesktopOnly: true`); uses Electron APIs.

## Test tooling (US-001, added 2026-10-30)

- vitest 3.2.7 (exact). Vitest 5 needs Vite 8, whose optional peers
  `esbuild` ≥ 0.27 and `@types/node` ≥ 20.19 conflict with upstream's
  esbuild 0.14.47; Vitest 3's Vite 7.3.7 carries its own esbuild 0.28.2,
  the plugin keeps 0.14.47 (measured `npm ls esbuild`).
- prettier 3.9.10 (exact).
- jsdom 26.1.0 and @types/jsdom 21.1.7 (exact; US-002 D4): the Vitest
  environment for DOM unit tests (`// @vitest-environment jsdom`). Chosen
  after measuring: happy-dom 20.14.6 keeps a `<div>` inside a `<p>` when
  parsing; jsdom moves it out as the HTML specification and Chromium do.
  Bundle unchanged (`9baacf79…`), no installed version moved.
- @types/node 20.19.9 (exact; was ^16.11.6): Vitest 3 needs ≥ 18; 22.x
  breaks upstream `tsc` (2 errors in `src/plugin/utils/path.ts`); 20.19.9
  and 18.19.130 compile.
- postcss pinned to `8.4.47` (exact; was ^8.4.47): installing Vitest
  lifted it to 8.5.32, which changes the shipped bundle; the pin keeps the
  runtime version, Vite gets its own nested copy.
- nanoid 3.3.7 → 3.3.20 (through postcss): changes the bundle in 8 lines,
  the fix of CVE-2024-55565 (affected < 3.3.8); accepted by the user
  2026-10-30. Bundle sha256 before `628d062c…`, after `9baacf79…`.
