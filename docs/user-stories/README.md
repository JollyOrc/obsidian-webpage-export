# User Stories

This is the authoritative source of truth for product behaviour.
All implementation, tests, and documentation must align with it.

Each user story lives in its own file: `US-NNN-short-title.md`, made from
[`_TEMPLATE.md`](_TEMPLATE.md). Update the index table below whenever a story
is added or its status changes.

Upstream behaviour (the plugin as forked at 1.9.2) is not described by
stories; a story is written when the fork changes or relies on it.
